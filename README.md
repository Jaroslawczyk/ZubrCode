# ZubrCode — черновик

Это черновик-пример визуала студии, а не сайт и не демо-версия.

Состав `brand/`:
- `style-preview.html` — превью главной: тема, мозаика, орнаменты, помощник.
- `zubr-pixel.svg` — пиксельный зубр (символ), палитра сайта.
- `zubr-run.html` — мини-игра «Зубр» (прототип).

Открыть: двойной клик по `brand/style-preview.html` в браузере.
Без сервера, без сборки. Внешних зависимостей нет.
